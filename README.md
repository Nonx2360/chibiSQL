# ChibiSQL - Anime SQLite Editor 🌸⚡

Anime-themed SQLite Database Reader & Editor for VS Code, Cursor & Antigravity IDE.

## Features

- 🌸 **Anime Tokyo Night Aesthetic:** Dark pastel UI with cute status badges and neon accents.
- ⚡ **Lightweight & Fast:** Powered by WebAssembly (`sql.js`), no native C++ rebuilds needed.
- 📂 **Auto-associations:** Opens `.db`, `.sqlite`, and `.sqlite3` files automatically in Custom Editor.
- 🔍 **Interactive Explorer:** Browse tables and view row data instantly.
- 💻 **SQL Query Console:** Run arbitrary queries with `Ctrl+Enter`.

## Usage

1. Open any `.db`, `.sqlite`, or `.sqlite3` file directly in VS Code / Cursor / Antigravity IDE.
2. Select a table from the sidebar to inspect records.
3. Write custom queries in the console and hit **Run Query (Ctrl+Enter)**.

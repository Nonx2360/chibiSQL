Got Questions?

Frequently Asked Questions

Does ChibiSQL work in Cursor and Antigravity IDE? ▼

Yes! Because Cursor and Antigravity IDE share the VS Code extension runtime architecture, ChibiSQL installs and functions smoothly across all VS Code compatible editors.

How does ChibiSQL handle large SQLite databases? ▼

ChibiSQL performs server-side (in-process WASM) SQL pagination using LIMIT and OFFSET. Only the 50 rows currently on screen are rendered into the DOM, making navigation snappy even with tables containing over 100,000 rows.

Are image BLOBs supported? ▼

Yes! ChibiSQL automatically recognizes PNG, JPEG, GIF, WebP, and BMP binary headers (including the Northwind 78-byte OLE offset). It displays thumbnails right in the table cell with a full preview in the record inspector.
